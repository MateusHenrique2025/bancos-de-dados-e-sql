# Projeto Integrador - [Mateus Henrique de Souza Pinheiro]
**Turno:** Noturno 
**Stack:** PHP + MySQL

## Como rodar o projeto:
1. Importe o banco `escola_db` no MySQL.
2. Coloque o arquivo `app/index.php` dentro da pasta `htdocs` do XAMPP (pode criar uma pasta chamada `projeto_iteam`).
3. Inicie o Apache no XAMPP.
4. Acesse no navegador: http://localhost/projeto_iteam/
