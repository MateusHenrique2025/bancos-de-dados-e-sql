# Entregas do Projeto Integrador (Individual)

Prazo final: **Domingo, 15/11/2026 até as 23:59** (via Fork + Pull Request, sem apresentação oral).

## Como criar sua entrega
1. Copie a pasta [`_modelo-individual/`](./_modelo-individual/) para o seu turno com o seu nome em minúsculas e sem acentos:
   * `entregas/noturno/nome-sobrenome/`
   * `entregas/vespertino/nome-sobrenome/`
2. Preencha o `README.md`, coloque o código em `app/`, os scripts em `sql/` e o DER em `der/`.
3. Faça commit apenas da sua pasta e abra um Pull Request no GitHub.

Leia os detalhes completos em [`docs/projeto-integrador.md`](../docs/projeto-integrador.md).
