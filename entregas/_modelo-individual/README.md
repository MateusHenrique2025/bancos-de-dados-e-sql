# Projeto Integrador - Nome Completo

* **Aluno:** Nome Completo
* **Turno:** Noturno / Vespertino
* **Stack utilizada:** (ex.: HTML/CSS/JS + Node.js / Python / PHP + MySQL)

## Como executar localmente
1. Importe o banco `base/escola_db.sql` no MySQL/MariaDB.
2. Execute eventuais scripts extras da pasta `sql/`.
3. Configure as variáveis de ambiente (sem subir `.env` com senha no Git).
4. Inicie a aplicação dentro de `app/`.

## O que foi implementado
* Listagem de alunos matriculados com nome, e-mail, turma, data da matrícula, notas e média final.
* Filtro por turma e busca por nome.
